### Overall Evaluation

**1. Working Environment**  
The working environment at AWS Vietnam is very professional, modern, and supportive. The FCJ program provides an excellent learning atmosphere where interns can work on real-world cloud projects. The office space is well-equipped with all necessary resources, and the remote work flexibility allows for a good work-life balance. The team members are always approachable and willing to help, creating a collaborative environment that encourages learning and growth.

**2. Support from Mentor / Team Admin**  
My mentor provided exceptional guidance throughout the internship. They took time to explain complex AWS concepts, reviewed my code and architecture decisions, and always encouraged me to explore and learn independently. The mentor's approach of letting me solve problems first before providing hints was very valuable for my learning. The admin team was also very supportive, helping with onboarding, access to AWS resources, and any administrative needs. The regular check-ins and feedback sessions helped me stay on track and continuously improve.

**3. Relevance of Work to Academic Major**  
The FCJ program perfectly aligned with my interest in cloud computing and software engineering. Working on a DevSecOps project with FastAPI, AWS Lambda, and Terraform allowed me to apply theoretical knowledge from university (distributed systems, software engineering, security) to real-world scenarios. The project introduced me to industry best practices like Infrastructure as Code, CI/CD pipelines, and security scanning that I hadn't learned in school, making it a perfect bridge between academia and industry.

**4. Learning & Skill Development Opportunities**  
The internship provided tremendous learning opportunities. I gained hands-on experience with:
- **AWS Services**: Lambda, API Gateway, DynamoDB, ECR, Secrets Manager, CloudWatch
- **DevOps Tools**: GitLab CI/CD, Terraform, Docker
- **Security**: Semgrep (SAST), Trivy (container scanning)
- **Best Practices**: Serverless architecture, Infrastructure as Code, automated testing

The program also included access to AWS training resources, documentation, and the opportunity to attend internal tech talks. The mentor shared valuable insights about cloud architecture patterns and career development in the tech industry.

**5. Company Culture & Team Spirit**  
AWS culture emphasizes customer obsession, ownership, and innovation. Even as an intern, I felt valued and was encouraged to contribute ideas. The team follows AWS's leadership principles, especially "Learn and Be Curious" and "Dive Deep," which created an environment where asking questions and exploring solutions was always welcomed. The collaborative spirit and willingness to help each other made me feel like a real part of the team.

**6. Internship Policies / Benefits**  
The FCJ program offers competitive internship benefits including a stipend, flexible working hours, and access to AWS training and certification resources. The program structure allows interns to work on meaningful projects while balancing academic commitments. The opportunity to work with cutting-edge cloud technologies and learn from experienced AWS professionals is invaluable.

### Additional Questions

**What did you find most satisfying during your internship?**  
The most satisfying aspect was seeing my project come to life - from writing project code to deploying it on AWS Lambda with a fully automated CI/CD pipeline. The moment when I successfully deployed the infrastructure using Terraform and saw the API working in production was incredibly rewarding. Additionally, learning about security scanning and implementing DevSecOps practices gave me confidence in building secure applications.

**What do you think the company should improve for future interns?**  
While the program is excellent, I think it would be beneficial to:
- Have more structured workshops on specific AWS services (e.g., deep dives into Lambda, DynamoDB)
- Organize more networking events with other FCJ interns and AWS employees
- Provide more opportunities to present work to a broader audience
- Include more guidance on AWS certifications and career paths

**If recommending to a friend, would you suggest they intern here? Why or why not?**  
Absolutely yes! I would highly recommend the FCJ program to any student interested in cloud computing, DevOps, or software engineering. The program offers:
- Real-world project experience with modern technologies
- Excellent mentorship and learning resources
- Exposure to industry best practices
- A supportive and collaborative environment
- Valuable experience for future career opportunities

### Suggestions & Expectations

**Do you have any suggestions to improve the internship experience?**  
1. **Extended Duration**: Consider offering longer internship periods (6 months) for more in-depth projects
2. **Project Variety**: Offer different project tracks (e.g., ML/AI, data engineering) to match different interests
3. **Certification Support**: Provide more structured support for AWS certification preparation
4. **Alumni Network**: Create a network for FCJ alumni to stay connected and share opportunities

**Would you like to continue this program in the future?**  
Yes, I would love to continue with AWS in the future, either through a full-time position or an extended internship. The experience has been transformative, and I'm excited about the possibility of contributing to AWS's mission of helping customers build on the cloud.

**Any other comments (free sharing):**  
The First Cloud Journey program exceeded my expectations. It's not just an internship - it's a comprehensive learning experience that prepares students for careers in cloud computing. The combination of hands-on projects, excellent mentorship, and exposure to AWS culture makes this program unique. I'm grateful for this opportunity and would encourage any student passionate about cloud technology to apply. Thank you to the FCJ team, my mentor, and everyone at AWS Vietnam for this incredible experience!
