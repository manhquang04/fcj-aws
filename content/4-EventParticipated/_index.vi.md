&emsp;**Thời gian:** Thứ Bảy, ngày 15 tháng 11 năm 2025, 8:30 – 12:00

&emsp;**Địa điểm:** Văn phòng AWS Vietnam

&emsp;**Vai trò trong sự kiện:** Người tham dự

&emsp;**Mô tả:** Workshop thực hành về Amazon SageMaker cho các quy trình ML truyền thống và Amazon Bedrock cho các ứng dụng generative AI, bao gồm kiến trúc RAG, prompt engineering và Bedrock Agents.

&emsp;**Nội dung nổi bật:**
- Tổng quan Amazon SageMaker: chuẩn bị dữ liệu, training mô hình, triển khai và MLOps

- Generative AI với Amazon Bedrock: so sánh và lựa chọn foundation models
- Kỹ thuật prompt engineering: Chain-of-Thought reasoning và Few-shot learning
- Kiến trúc Retrieval-Augmented Generation (RAG) và tích hợp knowledge base
- Bedrock Agents cho quy trình đa bước và tích hợp công cụ
- Guardrails cho an toàn và lọc nội dung
- Demo trực tiếp: Xây dựng chatbot generative AI bằng Bedrock

### [Event 4](4.4-Event4/)
&emsp;**Tên sự kiện:** Workshop DevOps trên AWS

&emsp;**Thời gian:** Thứ Hai, ngày 17 tháng 11 năm 2025, 8:30 – 17:00

&emsp;**Địa điểm:** Văn phòng AWS Vietnam

&emsp;**Vai trò trong sự kiện:** Người tham dự

&emsp;**Mô tả:** Workshop toàn diện cả ngày về các dịch vụ DevOps AWS bao gồm CI/CD pipelines với CodePipeline/CodeBuild/CodeDeploy, Infrastructure as Code với CloudFormation và CDK, container services (ECS, EKS, App Runner), và monitoring & observability với CloudWatch và X-Ray.

&emsp;**Nội dung nổi bật:**
- Văn hóa DevOps, nguyên tắc và DORA metrics (MTTR, tần suất triển khai)
- CI/CD pipeline: CodeCommit, CodeBuild, CodeDeploy với Blue/Green, Canary và Rolling updates
- Infrastructure as Code: CloudFormation templates và so sánh AWS CDK
- Container services: Docker cơ bản, ECR, ECS, EKS và App Runner
- Monitoring & observability: CloudWatch metrics/logs/alarms và AWS X-Ray distributed tracing
- DevOps best practices: feature flags, automated testing, quản lý sự cố
- Case studies: Chuyển đổi DevOps của startup và doanh nghiệp
- Lộ trình nghề nghiệp và roadmap chứng chỉ AWS

### [Event 5](4.5-Event5/)  
&emsp;**Tên sự kiện:** Workshop AWS Well-Architected Security Pillar  

&emsp;**Thời gian:** Thứ Bảy, ngày 29 tháng 11 năm 2025, 8:30 – 12:00  

&emsp;**Địa điểm:** Văn phòng AWS Vietnam  

&emsp;**Vai trò trong sự kiện:** Người tham dự  

&emsp;**Mô tả:** Workshop buổi sáng cung cấp cái nhìn chuyên sâu toàn diện về AWS Well-Architected Security Pillar, bao gồm tất cả năm domain bảo mật: Identity & Access Management, Detection, Infrastructure Protection, Data Protection, và Incident Response.  

&emsp;**Nội dung nổi bật:**
- Nền tảng Security: Least Privilege, Zero Trust, Defense in Depth, Shared Responsibility Model
- IAM: Users, Roles, Policies, IAM Identity Center, SCP, Permission Boundaries
- Detection: CloudTrail, GuardDuty, Security Hub, VPC Flow Logs, EventBridge automation
- Infrastructure Protection: VPC segmentation, Security Groups vs NACLs, WAF + Shield + Network Firewall
- Data Protection: KMS, encryption at-rest & in-transit, Secrets Manager, Parameter Store
- Incident Response: IR playbooks cho compromised IAM key, S3 public exposure, EC2 malware detection, auto-response với Lambda/Step Functions
